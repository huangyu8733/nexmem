# Nexmem 界面规范（对齐 QQ）

> 适用范围：Android / iOS / Windows / macOS / Linux / Web 六端共用一套 Flutter UI。
> 参考 QQ 的信息架构与交互习惯，**不使用** QQ 的素材、图标、商标与会员/装扮类模块。

---

## 1. 信息架构

| 层级 | 移动端 | 桌面 / Web |
|---|---|---|
| 一级 | 底部三 Tab：消息、联系人、我的 | 左侧功能栏：头像、消息、联系人、设置 |
| 二级 | 会话列表 → 聊天页 | 中间列表（会话/联系人）→ 右侧聊天区 |
| 三级 | 聊天页内「更多」面板 | 聊天区右侧可折叠资料面板（群成员/好友资料） |

响应式断点：宽度 `< 720px` 用移动布局，`>= 720px` 用三栏布局。Web 与桌面共用三栏。

---

## 2. 消息列表

- 顶部：搜索框、`+`（发起单聊/建群/加好友）。
- 会话项高度 56px，左右内边距 12px：
  - 左：44px 圆角头像，右上角在线状态点（在线/中继/离线）。
  - 中：昵称（16px，未读时加粗）、最后一条消息摘要（14px，单行省略）。
  - 右：时间（HH:mm / 昨天 / 周几）、未读红点（超过 99 显示 `99+`）。
- 状态标记：置顶（浅灰底）、免打扰（小铃铛斜线）、发送失败（红色感叹号）。
- 排序：置顶优先，其余按最后消息时间倒序。
- 交互：左滑「标记已读 / 删除」；桌面右键菜单同能力。

---

## 3. 聊天页

- 顶部栏：返回（移动端）、标题（单聊昵称 / 群名 + 成员数）、更多（清空、举报、群设置）。
- 消息区：
  - 时间分隔条：间隔超过 5 分钟显示。
  - 自己：右侧，主色气泡，白字；对方：左侧，白色/浅灰气泡，深色字；群聊在气泡上方显示发送者昵称。
  - 状态：发送中（转圈）、已送达（单勾）、已读（双勾）、失败（红色感叹号，点击重发）。
  - 新消息到达时若已滚动到底部则自动跟随，否则显示「N 条新消息」浮标。
- 底部输入区：
  - 工具条：语音、表情、图片、文件。
  - 多行输入框，`Enter` 发送、`Shift+Enter` 换行（桌面/Web）；移动端键盘发送键。
  - 发送按钮在主色圆角矩形内。
- 长按/右键消息：复制、转发、撤回（仅自己，2 分钟内）、删除。

---

## 4. 联系人

- 分组：好友、群聊、我的设备。
- 好友列表：字母索引（A–Z + `#`），行高 56px，右侧展示备注名。
- 好友资料页：头像、昵称、账号 ID（可复制）、设备列表、备注、拉黑、发消息。
- 群资料页：群名、成员网格、群盘状态（未配置时显示常驻提示）、退群/解散。

---

## 5. 我的 / 设置

- 账号卡片：头像、昵称、账号 ID、设备名。
- 分组项：
  - 账号与安全：设备证书、备份导入导出。
  - 网络：连接状态、中继开关、网络诊断（DHT 耗时、打洞结果）。
  - 离线存储：开启/关闭、云厂商配置与自检。
  - 外观：浅色/深色/跟随系统。
  - 关于：版本、开源许可、诊断导出。
- Web 端额外显示：「仅在线接收」说明与令牌轮换入口（若由网关提供）。

## 6. 视觉令牌

| 项 | 值 |
|---|---|
| 主色 | `#12B7F5`（QQ 蓝） |
| 成功 / 警告 / 危险 | `#2BB673` / `#F5A623` / `#E5484D` |
| 浅色背景 | 页面 `#F2F2F2`，卡片 `#FFFFFF` |
| 深色背景 | 页面 `#111214`，卡片 `#1C1D1F` |
| 文字 | 主 `#1A1A1A`，次 `#8C8C8C`（深色模式取反） |
| 圆角 | 列表项 8，气泡 8–12，头像 50% |
| 间距 | 4 的倍数（4/8/12/16/24） |
| 字体 | 系统默认（Android Roboto、iOS SF、桌面/Web 系统 UI 字体） |

图标统一使用线性图标库，不复制 QQ 图标。

## 7. 去中心化差异（与 QQ 的刻意差异）

| 场景 | 展示 |
|---|---|
| 连接状态 | 顶部细状态条：`在线` / `经中继` / `离线`，点击展开诊断 |
| 发送失败 | 气泡旁红色感叹号 + 点击重发，不静默丢失 |
| 对方未开启离线存储 | 输入区上方提示「对方未开启离线存储，仅支持在线发送」 |
| 设备多端 | 资料页展示设备列表与最近活跃时间 |
| Web | 首次进入提示「浏览器关闭后不再实时接收」 |
| 群盘未配置 | 群资料页常驻提示「未配置群盘，离线消息不可补」 |

---

## 8. 状态与空态

- 空会话列表：「暂无会话，点击 + 发起聊天」。
- 断网：顶部状态条变灰 + 会话列表顶部提示「网络已断开，正在重连」。
- 搜索无结果：居中提示 + 清除按钮。
- 加载中：骨架屏（会话列表 6 行），不使用整页转圈。

---

## 9. 桌面 / Web 快捷键

| 快捷键 | 行为 |
|---|---|
| `Ctrl/Cmd + F` | 聚焦搜索 |
| `Ctrl/Cmd + N` | 新建会话 |
| `Enter` | 发送（输入框内） |
| `Shift + Enter` | 换行 |
| `Esc` | 关闭弹层 / 返回会话列表 |

---

## 10. 验收口径

1. 六端截图对照本规范逐项检查：信息架构、列表行高、气泡方向、状态标记。
2. 移动端底部 Tab 切换不丢滚动位置与输入草稿。
3. 桌面/Web 在 720px 断点前后布局正确切换。
4. 深色模式下对比度满足 WCAG AA（正文 ≥ 4.5:1）。
