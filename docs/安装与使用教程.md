# Nexmem（奈讯联）安装与使用教程

本文面向终端用户，介绍如何从 GitHub 下载安装包并安装使用 Nexmem。应用英文名 **Nexmem**，中文名 **奈讯联**，两者指同一软件。

## 一、下载

打开 releases 页面：**https://github.com/huangyu8733/nexmem/releases/latest**

下载与你的设备对应的文件（版本号以实际发布为准）：

| 设备 | 文件名示例 | 大小约 |
| --- | --- | --- |
| Windows 10/11 (64 位) | `Nexmem-1.1.0-windows-x64.zip` | 100 MB |
| macOS (Apple Silicon / M 系列) | `Nexmem-1.1.0-macos-arm64.zip` | 150 MB |
| Linux x86-64 (Debian/Ubuntu) | `Nexmem-1.1.0-linux-x64.deb` | — |
| Linux x86-64 (通用) | `Nexmem-1.1.0-linux-x64.tar.gz` | — |
| Android 8.0+ | `Nexmem-1.1.0-android.apk` | 100 MB |
| 任意设备的浏览器 | `Nexmem-1.1.0-web.zip` | — |

> **iOS 说明**：仓库包含完整 iOS 工程与内核 XCFramework，代码层面与其余五端共用同一契约；当前 Release 工作流尚未产出正式 IPA，需在 macOS 上按 README 的源码构建方式用 Xcode 安装到真机，或由二次开发者自行签名上架。
>
> 各功能界面的实际截图见 [README 界面预览](../README.md#界面预览)，包含桌面三栏、移动底部 Tab、账号发现、远程设备与 RTL 布局。

## 二、应用内在线升级（推荐）

桌面端与 Android 用户无需手动下载：打开 **设置 → 关于 → 检查更新**，应用会从 GitHub
查询最新版。若有新版本，会展示 Release 说明并提供「下载安装包」按钮；下载进度实时显示，
完成后点「打开安装目录」：

- **Windows**：运行目录内的 `install.ps1`，按提示完成升级；
- **macOS / Linux**：解压后按「三、按平台安装」中的步骤覆盖安装；
- **Android**：点击下载的 APK 安装（需允许安装未知来源应用）；
- **Web**：浏览器版不支持就地升级，请回到 releases 页面手动下载。

升级过程不会删除本地账号与聊天数据（数据目录与安装目录分离）。若检查更新失败，可点
「打开发布页」手动下载。

## 三、按平台安装

### Windows

1. 下载 `Nexmem-<版本>-windows-x64.zip`。
2. 右键 → 全部解压缩到任意目录，例如 `D:\Nexmem`。
3. 两种方式任选：
   - **免安装运行**：进入解压目录，双击 `nexmem_app.exe`。
   - **安装到开始菜单**（推荐）：在解压目录的地址栏输入 `powershell` 并回车，执行：
     ```powershell
     powershell -ExecutionPolicy Bypass -File .\install.ps1
     ```
     安装后可从开始菜单搜索「Nexmem」启动。卸载执行同目录下的 `uninstall.ps1`。
4. 若 Windows 提示「Windows 已保护你的电脑」，点击「更多信息」→「仍要运行」（安装包未购买代码签名证书）。

> 注意：不要把 `nexmem_app.exe` 单独移出文件夹，同目录的 `nexmem.dll`、`data/`、`flutter_webrtc_plugin.dll` 等都是运行必需文件。

### macOS（Apple Silicon / M 系列）

1. 下载 `Nexmem-<版本>-macos-arm64.zip` 并解压，得到 `nexmem_app.app`。
2. 将应用拖入「应用程序」文件夹。
3. 首次打开：右键应用 →「打开」→「打开」；若仍被拦截，在「终端」执行：
   ```bash
   xattr -cr /Applications/nexmem_app.app
   ```
   然后再次打开。应用未做 Apple 开发者签名，这是正常提示。
4. 若你的设备是 Intel Mac，当前发布包不覆盖；可按 README 的源码构建章节在 Intel 机器上自行构建。

### Linux

**Debian / Ubuntu（推荐）**

```bash
sudo apt install ./Nexmem-<版本>-linux-x64.deb
nexmem
```

应用会出现在系统菜单中（名称 Nexmem）。卸载：`sudo apt remove nexmem`。

**通用 tarball**

```bash
tar -xzf Nexmem-<版本>-linux-x64.tar.gz
cd bundle
./nexmem_app
```

需系统已安装 GTK3、liblzma 等桌面运行库。tarball 内的 `libnexmem.so` 必须和主程序保持同一目录。

### Android

1. 在手机「设置 → 安全」中开启「安装未知来源应用」（允许浏览器/文件管理器安装 APK）。
2. 下载 `Nexmem-<版本>-android.apk` 并点击安装。
3. 首次启动时允许必要的本地通知权限。APK 使用调试签名，适合体验与内测；正式上架版本会使用正式签名。

### Web

1. 下载 `Nexmem-<版本>-web.zip` 并解压，例如解压到 `web` 目录。
2. 用任意静态服务器托管，例如：

   ```bash
   cd web
   python -m http.server 8080
   ```

   然后浏览器打开 `http://localhost:8080`。
3. 如果部署到公网，建议放在 Nginx / Caddy 后面并开启 HTTPS；浏览器只有在 HTTPS（或 localhost）下才允许麦克风/摄像头，语音视频通话功能依赖此条件。
4. Web 版本通过 Web 网关（webd）接入网络，首次使用需要配置网关地址与访问令牌；局域网体验可部署仓库中的 `deploy/web/` 组件，详见 `deploy/web/README.md`。

## 四、第一次使用

1. **设置资料**：进入「我的 → 个人资料」，填写昵称、个人介绍与推广信息；点击头像或推广图可上传并裁剪图片（头像固定 1:1 方形，推广图自由比例）。图片会自动压缩到 1024×1024 以内并以 base64 保存在本地。
2. **复制账号**：在个人资料卡片中点击复制按钮，复制完整账号 ID 发给好友。账号和设备 ID 过长时可用卡片上的左右小箭头平移查看，不会遮挡滚动条。
3. **添加好友**：同 WiFi 时进入「我的 → 账号发现」，点发现条目上的「加好友」即可；跨网时在「联系人 → 添加好友」输入对方账号，或扫描/分享二维码。
4. **发起聊天**：从好友列表或会话列表打开聊天，支持文本、文件与语音视频通话；聊天框右上角可直接发起远控（需对方确认）。
5. **远控与群组**：「我的 → 远程设备」录入被控设备并按类型勾选群控；「联系人 → 群聊」创建群聊、管理成员称呼与等级、设置群云盘与批量拉人。
6. **切换语言**：「设置 → 语言」选择界面语言，提供 33 个 locale 布局适配；其中简体中文（源文案）、繁体中文、英文、日语、阿拉伯语、希伯来语、韩语有完整译文，其余 locale 采用对应布局并回退英文文案。阿拉伯语和希伯来语会自动切换为从右到左布局。应用名称在多语言下显示为对应译名（英文 Nexmem / 中文 奈讯联等）。

## 五、常见问题

**Q：启动时报缺少 `nexmem.dll` / `libnexmem.so` / `libnexmem.dylib`？**
A：内核动态库需要和主程序放在同一目录。请重新完整解压 zip，不要单独复制 exe。

**Q：Windows 安装脚本执行失败？**
A：确认在解压目录执行，且 PowerShell 执行策略允许运行脚本（命令中已带 `-ExecutionPolicy Bypass`）。也可直接双击 `nexmem_app.exe` 免安装使用。

**Q：macOS 提示「已损坏，无法打开」？**
A：执行 `xattr -cr /Applications/nexmem_app.app` 移除下载隔离属性后重试。

**Q：Web 端无法语音/视频？**
A：确认通过 HTTPS 或 localhost 访问，且浏览器已授权麦克风/摄像头权限。

**Q：消息能离线发送吗？**
A：可以。桌面端为 P2P 直连 + 中继兜底，对方离线时消息会保留并在其上线后补发；群聊支持离线补齐。

**Q：怎么发起语音或视频通话？**
A：在单聊或群聊界面右上角点击语音/视频按钮即可。群聊通话最多 4 人，成员之间两两直连，通话页以网格显示所有成员；视频通话可开关摄像头、切换前后摄。通话内容端到端加密，不落盘、不录制。

部署步骤、防火墙端口、客户端接入方式与多中继池配置见 **[服务端公网部署](../deploy/server/README.md)**，Web 网关见 [Web 自托管部署](../deploy/web/README.md)。
